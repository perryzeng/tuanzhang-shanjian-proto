# 团长闪剪 · 交互原型工程

一页一个文件的可点原型。双击 `index.html` 就能用，不需要装任何东西、不需要起服务。

> 找入口看这里：项目根目录 `团长闪剪/index.html` 是入口壳，双击会自动跳到 `proto/index.html`（可带 `#/B2` 这类页面锚点）。原型本体在 `proto/` 子目录里。

---

## 怎么用

| 你想做的事 | 怎么做 |
|---|---|
| 看某一页 | 左侧页面树点一下；或用键盘 `←` `→` 翻页 |
| 走一遍链路 | 直接点手机里的按钮，就是真跳转 |
| 看这页有哪些出口 | 右侧「本页出口」，红色 = 指向还没迁进来的页面 |
| 看谁能走到这页 | 右侧「谁跳到这里」，没有入口说明这页是死路 |
| 切换同一页的不同状态 | 右侧「本页状态」（如发布器的浏览态/编辑态） |
| 给开发 | 右上「导出页面规格 CSV」/「复制链路清单」 |

URL 也能直接分享某一页：`index.html#/B2`、`index.html#/B2?mode=edit`。

## 怎么改一页

改 `js/pages/` 下对应的那一个文件，保存刷新即可。**其它 23 页完全不受影响**——这就是它比"一版一个大 HTML"值钱的地方。

- 改文案 / 加元素：直接改那个文件里的 HTML 字符串
- 加一个跳转：给元素加 `data-go="目标页ID"`
- 同一个页面换状态：给元素加 `data-set="B2.mode=edit"`
- 目标页还不存在也没关系，会跳到占位页，右侧面板会标红——这正是你要补的地方

## 怎么加一页（3 步）

1. `js/registry.js` 里那一行把状态改成已迁（清单里本来就有 24 页的坑位）
2. 新建 `js/pages/B2.2-shoot.js`：

```js
window.PAGES["B2.2"].render = function (ctx) {
  const C = window.C;
  return `<div class="app">
    ${C.sb()}
    ${C.ab({ title: "随手拍", sub: "拍 3 秒补素材", back: "B2" })}
    <div class="body">…你的内容…</div>
  </div>`;
};
```

3. `index.html` 里加一行 `<script src="js/pages/B2.2-shoot.js"></script>`

刷新，它会自动出现在左侧树、自动参与链路统计。

## 目录

```

├── css/tokens.css          设计令牌：主蓝 #2C5BFF · 青 #00C2FF · 紫 #7C5CFF + 四套渐变
├── css/ui.css              手机内组件样式（375×812 真机尺寸）
├── js/components.js        通用组件：页头 / 深色数据卡 / 图标行 / 列表项 / chips / 段卡 / Tab / 底部栏
├── js/core.js              路由、链路索引、面板、导出、缩放
├── js/pages/registry.js    24 页清单（标题/分组/说明），是页面树和统计的唯一来源
├── js/pages/*.js           一个文件 = 一页
├── assets/bn-1..3.jpg      首页 Banner 图片（可自由替换）
└── spec/
    ├── pages.csv           页面规格表（24 页 × 状态 × 出口数 × 出口目标）
    └── links.md            全量点击链路清单（按分组）
```

## 约定

- 手机尺寸固定 **375 × 812**，所有样式按真机写，不要再用缩略图的字号
- 页面根节点是 `<div class="app">`，内部依次是 `状态栏 → 导航栏 → .body（滚动区）→ 底部栏`
- 段卡统一走 `C.seg({...})`，四态：正常 / `on`（当前段）/ `dim`（非当前）/ `miss`（缺素材）
- 所有可点元素都要有 `data-go` 和 `data-label`，否则右侧链路会漏
- 未迁页面 = `PAGES[id].render` 为空，点击进占位页

## 视觉规范（全 24 页统一，改页时照着用）

| 层级 | 规则 |
|---|---|
| 底色 / 卡片 | 页面底 `#F6F8FC`，卡片纯白 + 圆角 20px + 极轻阴影（`--sh-1`） |
| 圆角 | 卡 20px · 大容器 26px · 按钮/胶囊 999px |
| 主色 | 蓝 `#2C5BFF`（主按钮、选中态、强调数字）；青 `#00C2FF` 作渐变副色；紫 `#7C5CFF` 只给「我的出镜 / 模板」类差异化区块 |
| 渐变 | `--g-brand` 主按钮 · `--g-tech` 数据条 · `--g-deep` 深色 hero · `--g-violet` 紫卡 |
| 深色数据卡 | 页头下方的关键数字用 `C.hero()`（深蓝渐变 + 白字 + 青色副数据），一页最多一块 |
| 导航 | 二级页 `C.ab()` 返回 + 大标题；一级页 `C.ph()` 大标题页头 |
| 列表 | 一律 `C.li()`：方形圆角缩略图 + 标题 + 两行说明 + 右侧蓝色胶囊动作 |
| 分类筛选 | 一律 `C.chips()` 横滑，选中 = 蓝底白字 |
| 底部 Tab | `C.tab()` 悬浮胶囊（距底 12px、左右 14px），选中项为蓝色胶囊 |
| 数字口径 | 万/亿用中文单位（8.6万），百分比保留 1 位小数 |

> 禁止：新的自定义色、直角卡片、实心阴影、在深色卡里用灰字。需要新增颜色先加进 `tokens.css`。
